# Hand-made government icons (set aside 26 November 2026)

LR's own government icon art, taken out of `gfx/interface/icons/government_types/` while the TEMP icon system is discussed (user: "comment out the hand made icons so my artist and I can discuss the system"). The game does not load this folder.

To restore one, move it back into `gfx/interface/icons/government_types/` (it replaces the TEMP icon of the same name), and remove its line from `GOVS` in `tools/gov_icons_from_emblems/build_temp_gov_icons.py` so a re-run does not overwrite it.
